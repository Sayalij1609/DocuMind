╔══════════════════════════════════════════════════════════════════════════════╗
║  SECTION 3 — DATA FORMAT SPECIFICATION                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

  FILE FORMAT   : Plain text (.txt), UTF-8 encoding, no BOM
  FILE SIZE     : 150–2000 bytes per file (matching existing data)
  FILE NAMING   : doc_XXXX.txt (sequential, 4-digit padded)
  CONTENT STYLE : Lowercase OCR-like text, minimal punctuation
                  (simulates Tesseract OCR output from scanned PDFs)
  NO HEADERS    : Do NOT include column headers like "Category: Invoice"
                  — the content itself is the only training signal
  ONE FILE = ONE DOCUMENT: Each file represents one complete document

  IMPORTANT RULES:
  ────────────────
  1. DO NOT include the category name as a label inside the file.
     The folder name IS the label.
  2. Vary company names, amounts, dates, addresses across files.
  3. Mix Indian (INR/GST) and international (USD/EUR/VAT) formats.
  4. Include realistic OCR noise: missing spaces, merged words,
     occasional typos (~5% of files) to improve robustness.
  5. Vary document lengths: some short (3-4 lines), some detailed
     (20-30 lines) to match real-world distribution.

║  SECTION 4 — DATA SOURCING STRATEGIES                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

  STRATEGY 1: SYNTHETIC GENERATION (FASTEST — RECOMMENDED)
  ─────────────────────────────────────────────────────────
  • Use ChatGPT / Gemini / Claude to generate realistic text samples
  • Prompt: "Generate 50 unique bank statement texts in OCR-extracted
    format, each with different bank names, account numbers, dates,
    transactions. Make them look like Tesseract OCR output."
  • Post-process: lowercase, remove excess formatting, save as .txt

  STRATEGY 2: TEMPLATE-BASED GENERATION
  ──────────────────────────────────────
  • Write Python scripts with templates + randomized values
  • Use Faker library for realistic names, addresses, amounts
  • Example: backend/scripts/generate_training_data.py (create this)
  • Best for: Invoices, Receipts, Salary Slips, Bank Statements

  STRATEGY 3: PUBLIC DATASETS
  ────────────────────────────
  • Kaggle "Invoice Dataset" — convert PDF text to .txt
  • RVL-CDIP document classification dataset (subset financial)
  • SEC EDGAR filings for Balance Sheets / P&L / Audit Reports
  • SROIE (Scanned Receipt OCR) dataset for receipts
  • IIT Bombay Financial NLP datasets

  STRATEGY 4: REAL DOCUMENT COLLECTION
  ─────────────────────────────────────
  • Collect actual documents (anonymize sensitive data!)
  • Scan → OCR → save text output
  • Most authentic but requires data privacy compliance

╔══════════════════════════════════════════════════════════════════════════════╗
║  SECTION 7 — HOW TO RETRAIN AFTER ADDING DATA                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

  Step 1: Place your .txt files in the correct category folders above.

  Step 2: Update the trainer's category list if needed:
          File: backend/app/ml/classification/trainer.py
          Ensure all new folder names are in CATEGORIES list.

  Step 3: Run the training command:
          ┌────────────────────────────────────────────────────┐
          │ cd backend                                         │
          │ python -m app.ml.classification.trainer             │
          └────────────────────────────────────────────────────┘

  Step 4: The trainer will output:
          • classifier.joblib  (trained model)
          • vectorizer.joblib  (TF-IDF vocabulary)
          • Training accuracy, F1-score per class
          • Confusion matrix

  Step 5: Verify by running tests:
          ┌────────────────────────────────────────────────────┐
          │ python -m pytest tests/ -v                          │
          └────────────────────────────────────────────────────┘

  Step 6: Restart the backend server to load the new model:
          ┌────────────────────────────────────────────────────┐
          │ python -m uvicorn app.main:app --reload             │
          └────────────────────────────────────────────────────┘
