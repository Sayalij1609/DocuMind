================================================================================
  CONVERSION METHOD 1: HTML → TEXT (Balance Sheets, Income Statements)
================================================================================

  Source Folders:
    data/Balance Sheets/   → data/classification/balance_sheet/
    data/Income Statement/ → data/classification/profit_loss/

  These are SEC filing HTML tables. Convert with this Python script:

  ┌─────────────────────────────────────────────────────────────────┐
  │  from bs4 import BeautifulSoup                                  │
  │  from pathlib import Path                                       │
  │                                                                 │
  │  src = Path("data/Balance Sheets")                              │
  │  dst = Path("data/classification/balance_sheet")                │
  │  dst.mkdir(parents=True, exist_ok=True)                         │
  │                                                                 │
  │  for i, html_file in enumerate(sorted(src.glob("*.html")), 1): │
  │      soup = BeautifulSoup(html_file.read_text(                  │
  │          encoding="utf-8", errors="ignore"), "html.parser")     │
  │      text = soup.get_text(separator=" ", strip=True)            │
  │      text = text.lower()[:2000]  # Keep under 2KB              │
  │      out = dst / f"doc_{i:04d}.txt"                             │
  │      out.write_text(text, encoding="utf-8")                     │
  │                                                                 │
  │  # Repeat for Income Statement → profit_loss                   │
  └─────────────────────────────────────────────────────────────────┘

  IMPORTANT: Install BeautifulSoup first: pip install beautifulsoup4


================================================================================
  CONVERSION METHOD 2: JPG → TEXT (Bank Statements, Salary Slips, ITR)
================================================================================

  Source Folders:
    data/Bank Statement/  → data/classification/bank_statement/
    data/Salary Slip/     → data/classification/salary_slip/
    data/ITR_Form 16/     → data/classification/tax_return/

  These are scanned document images. You need OCR to extract text.

  OPTION A: Tesseract OCR (Free, Local)
  ┌─────────────────────────────────────────────────────────────────┐
  │  # Install: https://github.com/tesseract-ocr/tesseract         │
  │  # pip install pytesseract Pillow                               │
  │                                                                 │
  │  import pytesseract                                             │
  │  from PIL import Image                                          │
  │  from pathlib import Path                                       │
  │                                                                 │
  │  src = Path("data/Bank Statement")                              │
  │  dst = Path("data/classification/bank_statement")               │
  │  dst.mkdir(parents=True, exist_ok=True)                         │
  │                                                                 │
  │  for i, img_file in enumerate(sorted(src.glob("*.jpg")), 1):   │
  │      img = Image.open(img_file)                                 │
  │      text = pytesseract.image_to_string(img).lower().strip()    │
  │      if len(text) > 50:  # Skip blank/failed OCR               │
  │          out = dst / f"doc_{i:04d}.txt"                         │
  │          out.write_text(text[:2000], encoding="utf-8")          │
  │                                                                 │
  │  # Repeat for Salary Slip → salary_slip                        │
  │  # Repeat for ITR_Form 16 → tax_return                         │
  └─────────────────────────────────────────────────────────────────┘

  OPTION B: EasyOCR (Better for non-English text)
  ┌─────────────────────────────────────────────────────────────────┐
  │  # pip install easyocr                                          │
  │  import easyocr                                                 │
  │  reader = easyocr.Reader(['en'])                                │
  │  results = reader.readtext(str(img_file), detail=0)             │
  │  text = " ".join(results).lower()                               │
  └─────────────────────────────────────────────────────────────────┘


================================================================================
  CONVERSION METHOD 3: CSV → TEXT (Bank Statements, Insurance)
================================================================================

  Source: data/bankstatements.csv
  Target: data/classification/bank_statement/

  This CSV has transaction rows. Convert each N rows into one statement:
  ┌─────────────────────────────────────────────────────────────────┐
  │  import pandas as pd                                            │
  │  from pathlib import Path                                       │
  │                                                                 │
  │  df = pd.read_csv("data/bankstatements.csv")                    │
  │  dst = Path("data/classification/bank_statement")               │
  │  dst.mkdir(exist_ok=True)                                       │
  │                                                                 │
  │  # Group every 10-20 transactions as one "statement"            │
  │  chunk_size = 15                                                │
  │  existing = len(list(dst.glob("doc_*.txt")))                    │
  │                                                                 │
  │  for i in range(0, len(df), chunk_size):                        │
  │      chunk = df.iloc[i:i+chunk_size]                            │
  │      lines = ["bank statement account transaction record"]      │
  │      for _, row in chunk.iterrows():                            │
  │          lines.append(                                          │
  │              f"{row['date']} {row['DrCr'].lower()} "            │
  │              f"{row['amount']} balance {row['balance']} "       │
  │              f"{row['mode'].lower()} {str(row['name']).lower()}"│
  │          )                                                      │
  │      lines.append(f"total transactions {len(chunk)}")           │
  │      text = "\n".join(lines)                                    │
  │      doc_num = existing + (i // chunk_size) + 1                 │
  │      out = dst / f"doc_{doc_num:04d}.txt"                       │
  │      out.write_text(text, encoding="utf-8")                     │
  └─────────────────────────────────────────────────────────────────┘

  Source: data/insurance_dataset.csv (tabular insurance claims)
  Target: data/classification/insurance_policy/
  Note: This CSV has claim data (Age, Gender, Income, Claim_Amount)
        Convert each row into a natural-language policy description.

  Source: data/data_synthetic.csv (detailed insurance customer data)
  Target: data/classification/insurance_policy/
  Note: Rich data with Coverage Amount, Premium, Deductible, etc.
        This is the BEST source for insurance training data.
  ┌─────────────────────────────────────────────────────────────────┐
  │  df = pd.read_csv("data/data_synthetic.csv")                    │
  │  dst = Path("data/classification/insurance_policy")             │
  │                                                                 │
  │  existing = len(list(dst.glob("doc_*.txt")))                    │
  │  for i, (_, row) in enumerate(df.iterrows()):                   │
  │      text = (                                                   │
  │          f"insurance policy\n"                                   │
  │          f"customer id {row['Customer ID']}\n"                   │
  │          f"age {row['Age']} gender {row['Gender']}\n"            │
  │          f"occupation {row['Occupation']}\n"                     │
  │          f"income {row['Income Level']}\n"                       │
  │          f"policy type {row['Policy Type']}\n"                   │
  │          f"coverage amount {row['Coverage Amount']}\n"           │
  │          f"premium amount {row['Premium Amount']}\n"             │
  │          f"deductible {row['Deductible']}\n"                     │
  │          f"policy start {row['Policy Start Date']}\n"            │
  │          f"renewal date {row['Policy Renewal Date']}\n"          │
  │          f"risk profile {row['Risk Profile']}\n"                 │
  │          f"credit score {row['Credit Score']}\n"                 │
  │      ).lower()                                                  │
  │      doc_num = existing + i + 1                                 │
  │      out = dst / f"doc_{doc_num:04d}.txt"                       │
  │      out.write_text(text, encoding="utf-8")                     │
  │      if i >= 999: break  # Limit to 1000 extra samples          │
  └─────────────────────────────────────────────────────────────────┘

  CONVERSION METHOD 4: SEC JSON → TEXT (Balance Sheets, P&L)
================================================================================

  Source: data/2015q3.json through data/2017q2.json
  Target: data/classification/balance_sheet/ AND profit_loss/

  These are HUGE SEC EDGAR filing JSON files (400-500 MB each).
  Each contains thousands of financial statements.

  WARNING: These files are very large. Process selectively:
  ┌─────────────────────────────────────────────────────────────────┐
  │  import json                                                    │
  │  from pathlib import Path                                       │
  │                                                                 │
  │  # Process just one file at a time (they are 400MB+!)           │
  │  with open("data/2015q3.json", "r") as f:                      │
  │      for line_num, line in enumerate(f):                        │
  │          if line_num > 5000: break  # Limit processing          │
  │          try:                                                   │
  │              record = json.loads(line)                           │
  │              # Extract text fields and save as .txt             │
  │          except: pass                                           │
  │                                                                 │
  │  NOTE: Only do this if you need MORE balance sheet /            │
  │  P&L data. You already have 270 HTML balance sheets +           │
  │  305 HTML income statements which is sufficient.                │
  └─────────────────────────────────────────────────────────────────┘


================================================================================
  FILE FORMAT RULES (CRITICAL!)
================================================================================

  Your training data .txt files MUST follow these rules:

  1. ENCODING    : UTF-8, no BOM
  2. CASE        : Lowercase (to match OCR output)
  3. SIZE        : 100-2000 bytes per file
  4. CONTENT     : Raw text only, no HTML tags, no headers
  5. LABELS      : The FOLDER NAME is the label. Do NOT put the
                   category name inside the file content.
  6. NAMING      : doc_XXXX.txt (4-digit zero-padded sequential)
  7. ONE FILE    : = One document
